PENUKONDA SAMACHAR - FREE WEBSITE

ఇది GoDaddy domain + free static hosting కోసం తయారు చేసిన mobile-first e-Paper website.

ఫైళ్లు:
- index.html
- config.js

రోజూ PDF మార్చడం:
1. మీ PDFకి public URL తీసుకోండి.
2. config.js లో pdfUrl విలువను ఆ URLతో మార్చండి.
3. date విలువను మార్చండి.
4. GitHub Pagesలో save/commit చేయండి.

GoDaddy domain:
- GitHub Pagesలో custom domainగా PenukondaSamachar.in జోడించండి.
- GitHub చూపించే DNS recordsనే GoDaddy DNSలో పెట్టాలి.
- HTTPS enable చేసిన తర్వాత site secureగా ఓపెన్ అవుతుంది.

గమనిక:
ఈ versionలో PDF viewer iframe ఉపయోగించబడింది. PDF URL publicగా ఉండాలి.
